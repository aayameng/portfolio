Step 0 of 0 · Start

From circles to n dimensions

Goal: volume and surface of the n-ball.

$$B_n=\{x\in\mathbb R^n:\ x_1^2+\cdots+x_n^2\le r^2\}$$
$$A=\pi r^2,\quad V=\tfrac43\pi r^3\ \Rightarrow\ V_n=\,?$$

Step 0 of 0 · 2D

2D: area from rings

Rings → strips → triangle.

$$dA=2\pi s\,ds$$
$$A=\int_0^r2\pi s\,ds=\pi r^2$$
$$A=\tfrac12\,C\,r=\tfrac12(2\pi r)\,r$$
$$C=\frac{dA}{dr}=2\pi r$$

Step 0 of 0 · 3D

3D: volume from slices

Stack disks of area A(z).

$$A(z)=\pi(r^2-z^2)$$
$$V=\int_{-r}^{r}\pi(r^2-z^2)\,dz=\tfrac43\pi r^3$$
$$S=\frac{dV}{dr}=4\pi r^2,\qquad V=\tfrac13\,S\,r$$

Step 0 of 0 · Scaling

Scaling: V = α rⁿ

Stretch every axis by r.

$$x_i=r\,y_i\ \Rightarrow\ dx_i=r\,dy_i$$
$$V_n(r)=r^n\!\int_{|y|\le1}\!dy=\alpha\,r^n$$
$$\alpha_1=2,\quad\alpha_2=\pi,\quad\alpha_3=\tfrac{4\pi}{3}$$

Step 0 of 0 · Shells

Shell: dV = α n rⁿ⁻¹ dr

Shell ≈ surface × thickness.

$$dV=\alpha\big[(r+dr)^n-r^n\big]=\alpha\,n\,r^{n-1}dr$$
$$n=1:\ 2\,dr\quad n=2:\ 2\pi r\,dr\quad n=3:\ 4\pi r^2dr$$

Step 0 of 0 · Choose a route

Find α for every n

Two routes, one answer.

Step 0 of 0 · Route A · 1

A1 · Gaussian by factoring

$$I=\int_{\mathbb R^n}e^{-|x|^2}dx=J^n,\quad J=\int_{-\infty}^{\infty}e^{-x^2}dx$$
$$J^2=\iint e^{-(x^2+y^2)}=2\pi\!\int_0^\infty\!re^{-r^2}dr=\pi$$
$$I=\pi^{n/2}$$

Step 0 of 0 · Route A · 2

A2 · Same integral by shells

Constant on each ring: value × shell.

$$I=\int_0^\infty e^{-r^2}\,\alpha n r^{n-1}dr$$
$$t=r^2:\quad\int_0^\infty r^{n-1}e^{-r^2}dr=\tfrac12\,\Gamma\!\left(\tfrac n2\right)$$
$$I=\frac{\alpha n}{2}\,\Gamma\!\left(\tfrac n2\right)$$

Step 0 of 0 · Route A · 3

A3 · Solve for α

$$\pi^{n/2}=\frac{\alpha n}{2}\Gamma\!\left(\tfrac n2\right)\ \Rightarrow\ \alpha=\frac{2\pi^{n/2}}{n\,\Gamma(n/2)}$$
$$\Gamma(s+1)=s\,\Gamma(s)\ \Rightarrow\ n\Gamma(\tfrac n2)=2\Gamma(\tfrac n2+1)$$
$$V_n=\frac{\pi^{n/2}r^n}{\Gamma\!\left(\tfrac n2+1\right)}$$

Step 0 of 0 · Route B · 1

B1 · One orthant

$$V_n=2^n\!\int_{x_i\ge0,\ |x|\le1}dx_1\cdots dx_n$$

Step 0 of 0 · Route B · 2

B2 · Square every coordinate

$$u_i=x_i^2,\qquad dx_i=\frac{du_i}{2\sqrt{u_i}}$$
$$|x|^2\le1\iff u_1+\cdots+u_n\le1$$

Step 0 of 0 · Route B · 3

B3 · A density appears

$$V_n=2^n\!\int_{\sum u_i\le1}\prod_i\frac{du_i}{2\sqrt{u_i}}$$
$$V_n=\int_{\sum u_i\le1}u_1^{-\frac12}\cdots u_n^{-\frac12}\,du$$

Step 0 of 0 · Route B · 4

B4 · Dirichlet integral

$$\int_{\sum u_i\le1}\prod u_i^{a_i-1}du=\frac{\prod\Gamma(a_i)}{\Gamma(\sum a_i+1)}$$
$$a_i=\tfrac12:\quad V_n=\frac{\Gamma(\frac12)^n}{\Gamma(\frac n2+1)}$$

Step 0 of 0 · Route B · 5

B5 · Find Γ(½)

$$\pi=V_2=\frac{\Gamma(\frac12)^2}{\Gamma(2)}=\Gamma(\tfrac12)^2$$
$$\Gamma(\tfrac12)=\sqrt\pi$$

Step 0 of 0 · Surface area

Surface area

Cones from the centre.

$$S_{n-1}=\frac{dV_n}{dr}=n\alpha_n r^{n-1},\qquad V_n=\frac rn\,S_{n-1}$$
$$S_{n-1}(r)=\frac{2\pi^{n/2}}{\Gamma(n/2)}\,r^{n-1}$$
$$V_n=\frac{2\pi}{n}V_{n-2}$$

Step 0 of 0 · Result

The volume of the n-ball

Peaks at n = 5, then falls to 0.

$$V_n=\frac{\pi^{n/2}}{\Gamma\!\left(\tfrac n2+1\right)}$$
$$V_1=2,\ V_2=\pi,\ V_3=\tfrac{4\pi}3,\ V_4=\tfrac{\pi^2}2,\ V_5=\tfrac{8\pi^2}{15}$$
$$V_n=V_{n-1}\int_{-1}^{1}(1-t^2)^{\frac{n-1}2}dt$$

Step 0 of 0 · Explore

Graphs and hidden patterns

$$V_n(r)=\frac{\pi^{n/2}}{\Gamma\!\left(\frac n2+1\right)}\,r^n,\qquad S_{n-1}(r)=n\,V_n(r)/r$$
$$V_n=\tfrac{2\pi}{n}V_{n-2},\qquad S_{n-1}(1)=n\,V_n(1)$$

Step 0 of 0 · Table

Surface ⇄ volume, every n

Pick n in the table: the graph above and the math follow.

$$S_{n-1}(r)=\frac{dV_n}{dr},\qquad V_n(r)=\int_0^rS_{n-1}(s)\,ds$$
$$\frac{d}{dr}\big(\alpha_nr^n\big)=n\alpha_nr^{n-1},\qquad\int_0^rn\alpha_ns^{n-1}ds=\alpha_nr^n$$
